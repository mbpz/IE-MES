# 六个生产工位入口重建

原仓库的维修、包装、抽检、SFC 工序、设备测试、外观检验 Controller 仅返回不存在的 JSP，未提供这些页面的原版表单或后端操作。用户没有 Eclipse 备份。本次按现有 SFC/质量数据模型实现可运行入口，不能推断或声称与失传页面行为完全相同。

## 行为边界

- 维修工位复用已有不良品处置页面与服务，继续由 `nc_handle` 权限控制；此流程原有的维修/报废业务状态更新保持原样。
- SFC 工序页按当前站点和 SFC 读取 `ly_shoporder_sfc` 与 `ly_sfc_step`，只读展示工单、SFC 状态和工序记录。
- 包装、抽检、设备测试、外观检验在新 `ly_station_event` 中记录 SFC、结果、记录编号、备注、操作人和时间。必须是当前站点已有且未报废的 SFC；包装只允许已完成 SFC 且每个 SFC 仅登记一次，事务中锁定 SFC 防止并发重复。
- 检测不通过只记台账，不自动创建不良记录；工位台账不改变 SFC/工单状态或库存。操作人员须通过现有不良处置流程继续处理。页面明确提示这个边界。
- 六个菜单资源只授予当前管理员角色，其他角色可通过权限管理单独授权。各工位页面及 API 使用各自权限键。
